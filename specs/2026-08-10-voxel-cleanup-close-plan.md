# Voxel Cleanup `close` Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `close` hole-filling mode — density-gated morphological closing — as an alternative to `grow`, for scenes whose holes are too wide for a neighbour-count fill to reach.

**Architecture:** Closing is `dilate(r)` then `erode(r)`, intersected with the candidate mask. The dilation already exists as a chunked, separable GPU pipeline; erosion is the same pipeline with `OR` replaced by `AND` and the out-of-range convention flipped from empty to occupied. That flip is the entire technical risk in this plan, and it has one non-obvious consequence documented below: the unused high bits of each dense row must be forced to 1, or erosion eats the grid's +X edge.

**Tech Stack:** TypeScript (ES2022, ESM), WGSL compute shaders via PlayCanvas, Node's built-in test runner, tsx, ESLint.

**Design spec:** `specs/2026-08-10-voxel-cleanup-design.md`
**Prerequisite plans:** all three must land first — `…-prereq-fixes-plan.md` (landed), `…-primitives-plan.md`, `…-integration-plan.md`

## The tail-bit hazard

Read this before Task 1; it is the reason this plan is not a two-line change.

The GPU dilation extracts a chunk into a dense **bit** buffer, 32 voxels per `u32`, with
`numXWords = (outerNx + 31) >>> 5`. `outerNx` is a multiple of 4 but not of 32, so the last word
of every row typically has unused high bits. After extract those bits are 0.

For dilation, extra zero bits are harmless: OR-ing with 0 changes nothing. For **erosion they are
fatal** — AND-ing with 0 clears every real voxel within `r` bits of the row end.

The halo saves the interior of most chunks: `blockAlignedExtent` rounds the halo up to a multiple
of 4 blocks, so inner positions sit at least `r` voxels from the outer boundary, and the unused
bits lie at or beyond it. But at the grid's **+X boundary** the outer region is clamped to the
grid, the halo there is 0, and inner positions sit right against the unused bits. That is exactly
where the erode convention must read "outside = occupied".

The fix is a small dispatch that sets bits `[outerNx, numXWords * 32)` of every row to 1, run
after extract and only on the erode path. Task 1 adds it.

Append to `src/lib/gpu/shaders/dilation.ts`:

```ts
/**
 * Row-tail fill shader — sets the unused high bits of each dense row to 1.
 *
 * The dense buffer packs 32 voxels per word, so when `outerNx` is not a multiple
 * of 32 the last word of every row carries unused high bits. Extract leaves them
 * 0, which dilation ignores but erosion would treat as empty space and eat the
 * real voxels beside them. One thread per row.
 *
 * @returns WGSL source for the row-tail fill compute shader.
 */
const fillRowTailWgsl = () => /* wgsl */`
struct FillTailUniforms {
    numXWords: u32,
    ny: u32,
    nz: u32,
    outerNx: u32
}

@group(0) @binding(0) var<uniform> u: FillTailUniforms;
@group(0) @binding(1) var<storage, read_write> dst: array<u32>;

@compute @workgroup_size(64)
fn main(@builtin(global_invocation_id) gid: vec3u) {
    let rowCount = u.ny * u.nz;
    if (gid.x >= rowCount) {
        return;
    }
    let used = u.outerNx & 31u;
    if (used == 0u) {
        return;
    }
    let lastWord = (u.outerNx + 31u) / 32u - 1u;
    let tailMask = ~((1u << used) - 1u);
    dst[gid.x * u.numXWords + lastWord] = dst[gid.x * u.numXWords + lastWord] | tailMask;
}
`;
```

Add `fillRowTailWgsl` and `type MorphOp` to the module's export list.

```ts
import { gpuDilate3, gpuErode3 } from './dilation';
import { sparseAndGrids, sparseOrGrids } from './grid-ops';
import { SparseVoxelGrid } from './sparse-voxel-grid';
import { type GpuDilation } from '../gpu';

/**
 * Result of {@link closeGrid}.
 */
type CloseResult = {
    /** The closed grid. */
    grid: SparseVoxelGrid;
    /** Voxels added. */
    added: number;
};

/**
 * Seal narrow gaps with a density-gated morphological closing.
 *
 * Computes `A | (erode(dilate(A, r), r) & candidate)`. Closing alone fills every
 * void narrower than `2r + 1` voxels regardless of whether it is a sampling
 * artifact or real geometry, so the result is intersected with `candidate`
 * before being unioned back: only gaps that have gaussian density behind them
 * get sealed.
 *
 * @param grid - Grid to close. **Consumed**: do not reuse it after the call.
 * @param candidate - Voxels permitted to be added. Not modified.
 * @param gpuDilation - Live GPU dilation pipeline.
 * @param radius - Closing radius in voxels.
 * @returns The closed grid and the number of voxels added.
 * @throws If `radius` is not a positive integer.
 */
const closeGrid = async (
    grid: SparseVoxelGrid,
    candidate: SparseVoxelGrid,
    gpuDilation: GpuDilation,
    radius: number
): Promise<CloseResult> => {
    if (!Number.isInteger(radius) || radius < 1) {
        throw new Error(`closeGrid: radius must be a positive integer, got ${radius}`);
    }

    const dilated = await gpuDilate3(grid, radius, radius, gpuDilation);
    const closed = await gpuErode3(dilated, radius, radius, gpuDilation);
    dilated.releaseStorage();

    // Only the newly sealed voxels need gating; the original grid passes through.
    const gated = sparseAndGrids(closed, candidate, true);

    let before = 0;
    grid.forEachOccupiedVoxel(() => before++);
    const merged = sparseOrGrids(grid, gated, true);
    let after = 0;
    merged.forEachOccupiedVoxel(() => after++);
    gated.releaseStorage();

    return { grid: merged, added: after - before };
};

export { closeGrid, type CloseResult };
```

Check `sparseOrGrids`' exact signature and `consumeA` semantics before relying on the calls above —
`grid-ops.ts:127` exports it and `test/dilation-grid-ops.test.mjs` exercises the consume path.
